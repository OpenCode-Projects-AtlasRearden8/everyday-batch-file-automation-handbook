The Everyday Batch-File Automation Handbook

Mass renames, format conversions, PDF/CSV joining and splitting, image resizing, and folder rules — with tested scripts and AI as your co-pilot.

A beginner-friendly, plain-English manual for one-off batch file jobs on Windows and Mac. Every recipe in the handbook is backed by a script in scripts/ that you can run today, and every script is covered by automated tests in tests/ — tests instead of prose, so you can trust what you copy-paste.

Written for people who are not programmers: registered nurses, small-business owners, authors, and anyone drowning in files. Explained like a friend would, never condescending.

Safety rule #1: every script in this handbook does a dry run by default. Nothing changes until you add --do-it. Read chapter 2 first.

Quick start

You need Python 3 (free) — see Ch. 1 for install steps on Windows and Mac.

# 1. Clone or download this handbook

# 2. Preview a rename (dry run — nothing changes yet)
python scripts/batch_rename.py ~/Downloads/shots --replace IMG_ IMG-

# 3. Hmm, that looks right. Actually do it:
python scripts/batch_rename.py ~/Downloads/shots --replace IMG_ IMG- --do-it

# 4. Test everything yourself (optional but satisfying)
python -m unittest discover -s tests -v

Two scripts need one optional helper each (exact commands in their chapters):

  • PDF chapters → pip install pypdf
  • Image chapters → pip install Pillow

Everything else (renames, CSVs, folder rules, the test suite) needs zero installs.

Verify it works

python -m unittest discover -s tests

All tests pass out of the box (PDF/image tests skip automatically if you haven't installed the optional helpers). Rebuild the website with python build_site.py — it regenerates everything in site/ from docs/.

Using AI as your script co-pilot

This handbook teaches a loop, not just files: (1) run a dry run, (2) check the preview, (3) commit with --do-it, (4) verify. Chapter 9 gives you copy-paste prompts to hand an AI assistant (like Claude, ChatGPT, or opencode) so it adapts these scripts to your exact mess — and the chapter insists you keep the dry-run habit even when the AI says "trust me."
